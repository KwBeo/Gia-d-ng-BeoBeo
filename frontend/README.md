# Frontend HomeEase

## Stack đã duyệt

- Node.js 24 LTS và npm
- Phiên bản Next.js stable với App Router
- TypeScript strict mode
- Tailwind CSS và ESLint

Các lựa chọn này đã được duyệt. Phiên bản Next.js stable cụ thể sẽ được chốt
khi tạo scaffold ứng dụng.

## Trách nhiệm

Nội dung hiển thị cho người dùng bằng tiếng Việt; giao diện khách hàng và
quản trị cần responsive. Frontend trình bày dữ liệu và gọi Flask REST API;
backend chịu trách nhiệm thực thi quyền truy cập và quy tắc nghiệp vụ.

## Trạng thái hiện tại

Thư mục này hiện chỉ có tài liệu setup. Mã nguồn ứng dụng, `package.json`,
lockfile và dependencies chưa được tạo. Xem
[`../docs/DEVELOPMENT_PLAN.md`](../docs/DEVELOPMENT_PLAN.md) để biết quy trình
phát triển local dự kiến.
