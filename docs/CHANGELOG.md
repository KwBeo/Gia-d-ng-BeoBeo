# Nhật ký thay đổi

Các mục dưới đây ghi nhận thay đổi tài liệu theo thời gian. Việc xuất hiện trong nhật ký không đồng nghĩa chức năng sản phẩm đã được triển khai.

## Chưa phát hành

### Phê duyệt stack và hoàn thiện tài liệu khởi tạo

- Ghi nhận stack đã duyệt: Node.js 24 LTS, npm, Next.js stable App Router, TypeScript strict mode, Tailwind CSS, ESLint; Python 3.13, Flask 3.x, pip/`venv`, SQLAlchemy, Flask-Migrate, REST API; PostgreSQL, Docker Desktop và Docker Compose.
- Bổ sung quy trình phát triển local và Git/GitHub branch workflow.
- Cập nhật hướng dẫn frontend/backend và quy tắc repository; chưa thêm mã nguồn ứng dụng, manifest dependencies hoặc cấu hình Compose.

### Tài liệu khởi tạo

- Thêm tổng quan, yêu cầu, kiến trúc mục tiêu, mô hình dữ liệu khái niệm, định hướng API và kế hoạch phát triển HomeEase bằng tiếng Việt.
- Ghi nhận phạm vi đồ gia dụng, vai trò khách hàng/quản trị viên, tìm kiếm/lọc, giỏ hàng, checkout COD, quản lý đơn hàng/tồn kho và xác thực/phân quyền.
- Đánh dấu các quyết định nghiệp vụ và kỹ thuật chưa được xác nhận là **TBD**.
- Không bao gồm mã nguồn ứng dụng; chưa có chức năng nào được khẳng định là đã triển khai hoặc kiểm thử.
